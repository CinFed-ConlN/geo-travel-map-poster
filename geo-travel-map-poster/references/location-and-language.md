# 坐标与地图标注语言

## 最小任务记录

先在本次任务记录中提炼下列信息，无须向用户展示一个表单：

| 项目 | 内容 |
| --- | --- |
| 照片 | 内容底图、风格参考、每张图片的位置归属 |
| 位置 | 原始坐标、来源、坐标系，或已有城市/区域线索 |
| 位置用途 | 拍摄点，还是用户明确指定的另一处地图目标 |
| 地图语言 | 用户指定值；没有指定时使用当地书写语言 |
| 文字限制 | 仅英文、双语、无文字、精确地名、不要显示坐标等 |
| 图片约束 | 比例、留白、主体保留、颜色、地图强度及位置 |
| 检索限制 | 是否禁止上传照片检索或限定检索范围 |
| 输出 | 成品海报、提示词，或明确要求的定位解释 |

用户后续给出新要求时先更新记录，再定位或作图。尤其不要在已经生成中文标签后才发现“地图用英文”。

## 语言与名称

| 地点 | 没有特殊要求时 | 名称核对原则 |
| --- | --- | --- |
| 中国大陆 | 中文、简体 | 如南昌、赣江；道路与地标用已核验的当地中文名 |
| 香港、澳门、台湾 | 当地惯用中文及字形 | 默认采用当地中文地名；当地双语名称可按用户要求加入 |
| 美国 | 美式英语 | 专名以当地官方/地图写法为准，描述性文字采用美式拼写 |
| 英国 | 英式英语 | 专名以当地官方/地图写法为准，描述性文字采用英式拼写 |
| 意大利 | 意大利语 | 如 Firenze，而非默认写 Florence；河流及地标保留已核验的意大利语原名 |
| 多语言国家/地区 | 所在地区当地惯用语言 | 如先核对比利时所在城市的语言，不能只凭国家固定选一种 |
| 其他地区 | 当地书写语言与原名 | 保留字形、重音符号及专名，不自动全部转写为英文 |

优先查用户提供的地图、当地市政/地标官方资料和可核验地图标签。英语要求下，城市可采用通行英文名称，街道和建筑优先使用官方英文名或稳定原名；没有可靠译名时保留原名，不自造直译。地名原文与最终标注分开记录。

英美变体只约束通用说明文字，不改写固有名称。用户仅说“英文”时，美国用 `en-US`，英国用 `en-GB`；其他国家可用中性英文；用户明确指定的变体覆盖位置默认值。回复语言、提示词语言和海报上可见文字是三个独立选项。

“地图用英文”约束地图可见的城市名、道路、河流、地标及图例；“整张海报用英文”还约束海报其他可见文字；“无文字”优先取消标签而非暗自保留小字；“中英双语”只对有限的关键标签使用并列写法，避免密集标注。

## 路线示例

- 用户给“纬度 31.2304，经度 121.4737，地图用英文”：先读照片信息，采用提供坐标，核对当地名称并准备英文标签；不再靠反向搜图找拍摄点，不把海报对话也切换为英文。
- 原图有有效 GPS，用户没有位置说明：采用 EXIF 的 WGS84 GPS，核对对应地区后决定当地语言；不能因为 GPS 值中有 0 就视为缺失。
- 照片明确标出 `41°54′N 12°30′E`：核对读数及其对应照片，转成十进制度后使用；默认当地意大利语标签。
- 用户只说“伦敦附近”：把该区域作为 geo-sleuth 初始搜索范围，定位后使用英式英语；不把伦敦市中心当成拍摄点。
- 用户没有位置线索：运行内置 geo-sleuth，再根据实际支持的位置选地图范围和当地语言。
- 用户同时给“罗马”与指向上海的坐标，未说明另一处目标：先询问以哪个位置为准；不默默改坐标，也不直接按城市名绕过坐标。
- 用户明确说“照片是在上海，但我要以罗马坐标为目标的海报”：使用用户指定的罗马目标，不声称照片是在罗马拍的。
- 用户给两个均小于 90 的裸数字且未说明顺序：如果无法从格式和上下文确认经纬顺序，先问顺序。

出现需要澄清的情况，把相关问题合并成一条简短问题；等待答案期间可继续识别主体、留白和风格，不能先确定冲突的地图目标。
