# 原始参考图：摩天轮与城市地图

查看 `../assets/style-reference.jpg`。这是手机播放器截图，中间作品约为 3:4 竖幅。忽略顶部状态栏、上下深色空白、底部播放器提示及系统手势条。

## 可见特征

- 实景主体：仰拍摩天轮，白灰色金属支架和大量辐条形成斜向弧线，左侧与底部出框，彩色轿厢沿右侧弧线排列。
- 背景：晴朗蓝天与白云，自然日光，结构线条清晰，保留真实摄影质感。
- 地图：集中在右上角，并沿右侧延伸；白色细道路、淡蓝色河道与浅色街区低对比融合进天空，向左下逐渐淡出，没有独立面板边框。
- 文字：可见城市名 `Nanchang`、地标名 `Star of Nanchang` 及河流名 `Gan River`，字小、浅色、偏衬线风格。依据这些可见文字描述参考，而非凭建筑外形判断地点。
- 标记：右上区域一个小型珊瑚红实心圆点；角落有小指北针与距离刻度。图中的刻度是视觉参考，不代表任意新作品也有可信比例尺。
- 层级：摩天轮及照片首先被看到，地图其次，红点提供局部焦点。没有醒目的营销标题或装饰画框。

## 同款提示词

原参考中的英文只说明它的可见内容，不决定新海报的语言。先采用根入口的语言规则：本例在没有特殊要求时用“南昌”“南昌之星”“赣江”；用户要求地图英文时才使用核验过的英文标注。

> 以我上传的摩天轮照片为基础，制作实景与城市地图融合的旅行海报。保留仰拍构图、摩天轮的钢架辐条、彩色轿厢以及蓝天白云，不改变主体透视。在右上方天空叠加清淡的南昌城市地图，使用白色纤细道路、淡蓝色赣江水系及低对比街区纹理，边缘通过渐变自然淡入天空，不出现矩形底板，不遮挡摩天轮。加入有依据的小型珊瑚红地点圆点，配以小号衬线文字“南昌”“南昌之星”，河流旁轻巧标注“赣江”（或按用户明确指定的语言使用最终标注清单），角落放一个小指北针。整体明亮通透、写实清晰，采用与主体适配的竖幅构图。去除手机状态栏、播放器文字和深色截图外框，不加大标题，不扭曲摩天轮，不添加无法核验的比例尺数字。

仅用于用户提供摩天轮底图并要求此款时；换成其他主体时改写构图和保留项。以真实地图数据绘制南昌时才声称地图准确。只求视觉效果时，将地图作为装饰纹理处理。

## 适配情形

| 照片 | 地图位置与处理 |
| --- | --- |
| 蓝天建筑或摩天轮 | 优先使用天空留白，白色细线与淡蓝水系，渐变避开建筑 |
| 城市夜景 | 使用深色留白，微亮灰白线，限制亮度，不统一改成蓝天风格 |
| 人物旅行照 | 使用人物之外的背景留白，不让地图覆盖脸和身体轮廓 |
| 山景、海岸 | 使用天空或水面留白，按需求选择道路、水系或等高线，保持清淡 |
| 无明显留白 | 缩小地图至一个角落或局部轻叠加，避免主体上铺满地图 |
